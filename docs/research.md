# Research: eGov және НУЦ РК ЭЦП жүйесі

## 1. Зерттелген ұйым
**eGov** (электрондық үкімет порталы) және **НУЦ РК** (Ұлттық куәландырушы орталық).
Азаматтар порталға ЭЦП арқылы кіреді, құжатқа электрондық қол қояды. НУЦ РК ЭЦП кілттерін
және сертификаттарды береді, ашық кілттің иесін растайды (PKI).

## 2. Ұйымның қызметі
- Азаматқа ЭЦП кілттерін беру (жабық кілт + сертификат, .p12 файл).
- Жүйеге кіру: сайт challenge жібереді, NCALayer жабық кілтпен қол қояды, сайт тексереді.
- Құжатқа қол қою: құжат хэшіне жабық кілтпен қол қойылады.
- Қосылымды TLS арқылы қорғау.

## 3. Акторлар
| Актор | Рөлі |
|---|---|
| Азамат | ЭЦП иесі, жүйеге кіреді, құжатқа қол қояды |
| НУЦ РК (куәландырушы орталық) | Сертификат береді, ашық кілт иесін растайды |
| eGov сервері | Қолтаңбаны тексереді, құжаттарды қабылдайды |
| Шабуылшы | Хабарды оқуға, өзгертуге немесе жалғандыққа тырысады |

## 4. Талаптар

### Функционалдық
1. Пайдаланушы тіркеледі, RSA кілт жұбы жасалады, ашық кілт серверде тіркеледі.
2. Қосылғанда сессия кілті RSA арқылы қауіпсіз алмасылады.
3. Хабар AES-GCM-мен шифрланады.
4. Әр хабарға SHA256withRSA қолтаңбасы қойылады, алушы тексереді.
5. Қолтаңба жарамсыз болса, хабар қабылданбайды.

### Қауіпсіздік талаптары
| Талап | Қалай қамтамасыз етіледі |
|---|---|
| Құпиялылық | AES-GCM |
| Түпнұсқалық | Цифрлық қолтаңба |
| Тұтастық | GCM authentication tag, хэш |
| Сенім | Сервер ашық кілттерді тіркейді (мини куәландырушы орталық), fingerprint |
| Replay қорғау | Хабар нөмірі (counter) |

## 5. Қауіптер
- **MITM:** ортада кілтті ауыстыру. Шешім: fingerprint.
- **IV қайталануы:** шешім: әр хабарға жаңа IV.
- **Replay:** шешім: counter.
- **Жабық кілттің ашық қалуы:** шешім: `.gitignore`, PBKDF2.

## 6. Жүйелерді салыстыру
| Жүйе | Кілт алмасу | Шифрлау | Растау |
|---|---|---|---|
| TLS/HTTPS | ECDHE/RSA | AES-GCM | Сайт сертификаты |
| Signal | X3DH | AES + Double Ratchet | Safety number |
| eGov ЭЦП | - | қол қою | НУЦ РК сертификаты |

## 7. Қорытынды
Жоба TLS шифрлауын және eGov ЭЦП қағидасын біріктіретін шағын чат. Сервер НУЦ РК-ның
шағын нұсқасы ретінде ашық кілттерді тіркейді.

*Ескерту: eGov техникалық бөлшектері өзгеруі мүмкін, ресми дерек: pki.gov.kz, egov.kz.*
